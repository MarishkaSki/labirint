# Лабиринт

- `npm start` — запуск: http://127.0.0.1:8123/ (нужен Node.js).
- `npm test` — проверка карты и столкновений.
- `npm install` → `npm run build` — обновление текстур после изменения материалов в `assets/textures/`, рецептов в `tools/build.cjs` или размеров домов в `static/game.js`. Результаты — в `static/generated/`.

**Публикация:** загрузите `index.html` и папку `static/` на сервер.
